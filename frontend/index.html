О системе и проекте

Наименование проекта: «Информационная система мониторинга состояния серверов»

Версия: 1.0.0

Репозиторий: github.com/AyBatv/monitoring_system

Лицензия: MIT License

Архитектура клиентской части (Frontend):

  • HTML5: семантическая разметка SPA-структуры, разделов и диалоговых окон;
  • CSS3: адаптивная блочная верстка, чистый минималистичный светлый дизайн на белом фоне;
  • JavaScript (ES6): асинхронное взаимодействие с REST API через Fetch API, валидация полей форм, динамическая перерисовка DOM.
